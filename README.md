# André Fernandes — CV

A self-contained, static CV for GitHub Pages. Open `index.html` directly or publish the repository from its root. No build step, framework, external font, or third-party service is required.

## Publish with GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, then select the default branch and `/ (root)`. GitHub Pages will serve `index.html` as the home page.

## Export to PDF

Click **Export to PDF**. The browser opens its print dialog with a two-page A4 layout. Choose **Save as PDF** as the printer/destination. For the closest match to the on-screen document, enable **Background graphics** if the browser offers that option.

The CV content was adapted from the supplied resume and NAU course certificate. The certificate's identity number is intentionally not included in the website.
